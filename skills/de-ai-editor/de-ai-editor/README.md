# de-ai-editor — AI 티 제거 문체 편집 패스

초안에서 "AI가 쓴 티"를 걷어내고 **사람이 쓴 문장**으로 되돌리는 편집 스킬입니다. 논지가 맞는데도 "GPT로 썼네" 소리를 듣는 글의 신뢰도를 올립니다.

## 언제 쓰나
- 보고서·개발의뢰서·임원 자료·대외 메일 초안이 "AI 같다" 싶을 때
- 상급자·외부로 보내기 직전 최종 문체 패스
- 발동어: "AI 티 빼줘", "사람이 쓴 것처럼", "GPT 같아", "밋밋해", "티 난다", "자연스럽게 다듬어"

## 쓰는 법
Claude 에게 초안을 주고 **"AI 티 빼줘"** 라고 하면 됩니다.
산출물: **개선본 + 전후 AI-티 지수(예: 7 → 2) + 무엇을 왜 고쳤는지 요약.**

## 뭘 안 하나 (안전장치)
- **없는 숫자·이름을 지어내지 않습니다.** 원문에 없으면 `[근거/수치 필요]`로 표시 → 사람이 채웁니다. (의료기기 데이터 무결성)
- 사실·용어·인용은 손대지 않고 **표현만** 바꿉니다.
- **관리·배포된 문서는 안 건드립니다**(변경관리 대상 → change-control).
- 규제 제출물은 표·정형·용어를 유지한 채 약하게만 손댑니다.
- 과교정 방지: "사람스럽게" 보이려 사실을 서사조로 윤색하지 않습니다("회의 발언"→"현장 얘기였음" 같은 것도 새 AI 티).

## 역할 분담 (다른 스킬과)
- 논지·구조가 안 서면 → **`structured-writing`** 먼저 (구조 잡기)
- 이 스킬(**de-ai-editor**) → 같은 뼈대를 **사람 문장으로** (문체·티 제거)
- HTML/PPT 포장 → **`html-report`** / **`ppt-brand-design`**

## 내 문체로 맞추기 (선택)
`assets/voice_profile.yaml` 에 본인 문체 카드를 두면, 재작성이 **본인 말투**로 나옵니다.
1. `assets/voice_profile.example.yaml` 을 복사해 `voice_profile.yaml` 로 저장
2. 본인이 손으로 쓴 글 1~2개(같은 성격)를 Claude 에게 주고 **"이 글로 voice_profile 채워줘"** 요청
3. 파일이 없으면 중립 비즈니스 문체로 동작합니다(문제 없음)

> ⚠️ `voice_profile.yaml` 은 **개인 문체**라 공유 레포에 올리지 않습니다(각자 로컬). 저장소엔 `voice_profile.example.yaml` 템플릿만 있습니다.
